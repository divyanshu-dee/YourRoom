# 🏠 YourRoom — Cozy Virtual Study Space

> A beautiful, interactive virtual lofi study room you can live in.

[![LIVE DEMO](https://img.shields.io/badge/LIVE-DEMO-orange?style=for-the-badge)](https://divyanshu-dee.github.io/YourRoom/)

## ✨ Features

- 🎵 **Lofi Music Player** — Three curated YouTube playlists (Lofi Hip Hop, Jazzy Study, Chill Beats)
- 💡 **Lighting Controls** — Toggle room light, desk lamp, fairy lights & candle with smooth transitions
- 🌧️ **Ambient Sounds** — Rain, thunder, fireplace, café noise, birds, and fan using Web Audio API
- ⏱️ **Pomodoro Timer** — Focus (25m), Short Break (5m), Long Break (15m) with circular progress
- 🌙 **Scene Modes** — Night, Sunset, Day, and Rainy scenes
- 🕐 **Live Clock** — Analog wall clock + digital screen clock with date
- ✍️ **Rotating Quotes** — Motivational quotes on the monitor
- ⭐ **Animated Stars** — Twinkling stars in the ceiling
- 🌧️ **Rain Animation** — Canvas rain drops + window rain effect
- ⌨️ **Keyboard Shortcuts** — Space=music, L=light, R=rain, P=pomodoro, Esc=panel

## 🚀 Quick Start

```bash
# Clone
git clone https://github.com/divyanshu-dee/YourRoom.git
cd YourRoom

# Open in browser (no build step needed!)
open index.html
```

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Space` | Play/Pause music |
| `L` | Toggle room light |
| `R` | Toggle rain |
| `P` | Start/Pause Pomodoro |
| `Esc` | Toggle control panel |

## 🛠️ Tech Stack

- **HTML5** — Semantic structure, CSS art room scene
- **Vanilla CSS** — Glassmorphism, animations, keyframes, grid layout
- **Vanilla JS** — Web Audio API, Canvas API, YouTube IFrame API
- **Google Fonts** — Outfit + Space Mono
- **Vercel** — Static hosting
